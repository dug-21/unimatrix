# crt-058 Acceptance Criteria Map

Traces every acceptance criterion (SCOPE AC-01…AC-09 + spec AC-10 subset invariant, AC-11 tuple audit) to a behavioral/state-based verification. Verification is state/parse-based, never call-count or bare string-presence (SR-04 discipline).

| AC-ID | Description | Verification Method | Verification Detail | Status |
|-------|-------------|--------------------|--------------------|--------|
| AC-01 | Both-direction agent-edge removal — deprecating E removes all `source='agent'` inbound (`target_id=E`) and outbound (`source_id=E`) edges synchronously. | test | Seed ≥1 inbound and ≥1 outbound `source='agent'` edge on Active E; `context_deprecate(E)`; query `graph_edges` by `target_id=E` and `source_id=E` filtered `source='agent'` → zero rows on return. | PENDING |
| AC-02 | Inline count reported — response includes count of edges removed. | test | Covered by AC-04 per-format matrix: assert rendered `edges_removed` value = N in each of Summary/Markdown/Json. | PENDING |
| AC-03 | Audit record content — removal recorded with entry id, count, and removed-edge tuples (ADR-002). | test | Deprecate E with N agent edges; read back audit record filtered `operation == "context_deprecate.edge_cleanup"`; assert `target_ids == [E]`, count N in `detail`, and N tuples in `metadata` (see AC-11). | PENDING |
| AC-04 | Per-source AND per-format behavioral matrix. | test | (a) Per-source: seed one edge of each `source` (`agent`, `nli`, `co_access`, `cosine_supports`, `S1`, `S2`, `S8`) touching E; deprecate; assert only `agent` removed, all machine sources remain. (b) Per-format: for N>0, render Summary/Markdown/Json; assert count value = N in each — Json parses the integer field (not substring); Summary/Markdown assert the rendered value. | PENDING |
| AC-05 | Zero case renders `Some(0)` — no agent edges → literal `0` in all three formats (ADR-004); advisory rendered, NOT omitted. | test | Deprecate E with zero `source='agent'` edges (machine edges may be present, must remain); assert `edges_removed = Some(0)`; assert each format renders literal `0` (Json integer field = 0); assert deprecation success otherwise unchanged. | PENDING |
| AC-06 | Non-fatal on failure — delete failure → normal success, `warn` logged, `edges_removed = None` (advisory omitted), tick sweeps later. | test | Fault-inject delete failure; assert `context_deprecate` returns success, entry is `Deprecated`, a `warn` log with entry id emitted, advisory omitted in all three formats (distinct from AC-05 `Some(0)`), agent edges still present; then run `run_orphaned_edge_compaction` and assert edges removed by backstop. | PENDING |
| AC-07 | Idempotency — re-deprecating an already-`Deprecated` entry performs no delete, reports no removal, writes no cleanup audit. | test | Deprecate E; seed a fresh `source='agent'` edge touching E; deprecate E again; assert second call returns via step-5 early-return, fresh edge untouched, no new `edge_cleanup` audit record for the second call. | PENDING |
| AC-08 | No new persistence / no tick change — reuses `graph_edges`, `write_pool_server()`, existing indexes. | file-check + grep | Assert schema version + migration list unchanged; `run_orphaned_edge_compaction` (`background.rs:805`) unchanged; grep the new helper uses `write_pool_server()` and targets `graph_edges`. | PENDING |
| AC-09 | Synchronous before response — edges absent immediately on return, no async defers them. | test | Immediately after `context_deprecate` returns (no tick, no sleep), query `graph_edges` and assert the agent-authored edges are already gone. | PENDING |
| AC-10 | eager ⊆ tick subset invariant (behavioral) — eager delete never removes an edge the tick would keep or repoint. | test | (1) Seed E with one edge per (direction × source); fixture A: bare-deprecate + run eager helper → capture R; fixture B (shared seed helper): bare-deprecate + run real `run_orphaned_edge_compaction` → capture T; assert R ⊆ T AND R == exactly the two `agent` edges. (2) Chokepoint-exclusion: drive `context_correct` (successor-bearing), assert eager helper never invoked — no `edge_cleanup` audit, inbound agent edge survives (R-01 closure). (3) Pin the LOCKED predicate string. | PENDING |
| AC-11 | Removed-edge tuples in audit (firm, ADR-002) — audit carries `(source_id, target_id, relation_type)` per eagerly-removed edge, not just a count. | test | Deprecate E with N agent edges of known tuples; read back the `edge_cleanup` audit record; assert `metadata` contains exactly the N tuples (set equality against the pre-delete edge set), well-formed JSON (not the `"{}"` sentinel). | PENDING |

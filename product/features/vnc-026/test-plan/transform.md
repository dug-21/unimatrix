# Test Plan: transform.js (host envelopes)

Oracle: `hook.rs:963-1028` (`write_stdout`, `write_stdout_subagent_inject`). ADR-002 (literal
templates; goldens are the byte authority). Risks: R-03, R-15, AC-03, AC-04.
Suite: `test/hook-client/transform.test.js` — byte-level comparisons against
`expected-stdout.bin` goldens.

## Envelope Byte Parity (AC-04 — byte-identical, not structural)

- `test_subagent_envelope_golden_bytes` — for every SubagentStart corpus case with a fixture `HookResponse`, output `===` golden bytes: exact form `'{"hookSpecificOutput":{"hookEventName":"SubagentStart","additionalContext":' + JSON.stringify(text) + '}}\n'` — compact, key order pinned, trailing newline.
- `test_plain_envelope_golden_bytes` — UserPromptSubmit/PreCompact: `body + '\n'` iff body non-empty; byte-compared.
- `test_empty_body_no_stdout` — 204 and 200-with-empty-body → zero bytes on stdout.

## Adversarial Inner-Scalar Escaping (R-03 — corpus adversarial cases, byte-compared vs Rust)

Golden-driven cases (JSON.stringify vs serde_json divergence hunting):
- control chars (0x00–0x1F dense), embedded `"` and `\`, emoji (non-BMP, 4-byte), lone-surrogate-adjacent sequences, U+2028/U+2029 (JS line separators — classic stringify divergence point), mixed CRLF.
- Each is a committed corpus case with `expected-stdout.bin` generated by the Rust oracle; assert byte equality. Any divergence is a release blocker for AC-04.

## Literal-Template Enforcement (ADR-002 grep-gate)

- `test_no_object_serialization_in_transform` — static gate: `transform.js` source contains exactly ONE `JSON.stringify` call site, and its argument is the inner text scalar — never an object literal/envelope. Implemented as a source-text assertion in the suite (fails loud if a refactor adds envelope serialization).

## Defensive Output Rules (R-15 tie-in)

- `test_nontext_200_produces_no_stdout` — transform invoked only for `text/plain` 200; given a non-text classification from transport, no bytes written (joint test with transport-http.md).
- `test_failure_paths_produce_no_stdout` — every transport failure class → transform not invoked / zero stdout (C-05).

## Concrete Assertions

- `renderEnvelope(event, body) -> Buffer|null` — pure; null means "write nothing".
- Output writes go to fd 1 exactly once per spawn at most; never partial writes interleaved with stderr.

## ADR-002: Stamp Attach as FNF-Path Decoration in index.js — buildRequest Stays Pure; Suppression by Strip; Delta Frames Unstamped

### Context

`buildRequest` is a pure parity port ("no I/O except process.ppid / process.cwd()", build-request.js header) and vnc-030 rebases onto vnc-027's edits to the same file (SR-09). The stamp requires file I/O (tracker read) plus access to `config.stateDir`, which only `index.js` has. The sync-path budget is binding: the sync trio (ContextSearch/CompactPayload/Ping) gains **no** extra file I/O; tracker reads are "one small JSON read on FNF builds". AC-03 requires extraction to emit no `topic_signal` while a stamp is active.

**Merged vnc-027 reality (verified 2026-06-08, F4a landed).** Two anchors this ADR now cites concretely rather than anticipates:
- *Narrowed matcher*: the PreToolUse install matcher is `lib/merge-settings.js:49` — `const PRETOOLUSE_CYCLE_MATCHER = "context_cycle|mcp__unimatrix__context_cycle";`. Only these two tool names spawn the hook on PreToolUse.
- *Null no-send sentinel*: lives in `lib/hook-client/build-request-tools.js`, function `buildCycleEventOrFallthrough` — returns `null` for any non-`context_cycle` PreToolUse (exact-equality gate F-02 at `build-request-tools.js:322-324`, sentinel return at `:326`; also `:334` missing tool_input, `:354` validation fail). `index.js:366` (`if (request === null) return;`) short-circuits the sentinel to exit 0 **before** transport selection (`selectTransport`, `index.js:410`). vnc-030 adds nothing to `build-request*.js`; the rebase surface is `index.js` orchestration only — confirmed against the merged tree.

### Decision

1. **All cycle-tracker I/O lives in `index.js`** (orchestrator), in a single decoration step between `buildRequest` (`index.js:360`) and transport dispatch (`runFireAndForget`, `index.js:414`). `build-request.js` / `build-request-tools.js` get **zero vnc-030 logic changes** (the rebase surface vs vnc-027 stays comment-level) — this is the smallest possible footprint on the shared file (SR-09). The narrowed matcher (`merge-settings.js:49`) and the sentinel (`build-request-tools.js:326`) are vnc-027's; vnc-030 consumes them unmodified.
2. **Ordering inside `main()`/`runFireAndForget`**:
   1. `request = buildRequest(...)` (pure, unchanged) — `index.js:360`.
   2. `request === null` (vnc-027 sentinel from `build-request-tools.js` `buildCycleEventOrFallthrough`) → return immediately at the existing `index.js:366` guard. **No tracker touch, no canary bump, no decoration** — the sentinel short-circuit precedes everything vnc-030 adds and precedes `selectTransport` (`:410`).
   3. FNF branch only (`RecordEvent`/`RecordEvents` — `SessionRegister`/`SessionClose` are not ImplantEvents and are skipped): **lifecycle dispatch** — if the frame's `event_type` is `CYCLE_START_EVENT`/`CYCLE_PHASE_END_EVENT`/`CYCLE_STOP_EVENT`, call `cycles.writeCycle`/`updatePhase`/`deleteCycle` (ADR-001). These constants are already re-exported by build-request.js.
   4. **Decoration** — one `cycles.readCycle(stateDir, sessionId)`:
      - file present → set `cycle_stamp: {topic, phase}` on **each** ImplantEvent in the frame (`phase` key omitted when null, matching `implantEvent` omit-when-null parity), and **delete `topic_signal` from every non-CYCLE_* frame** (suppression, AC-03). CYCLE_* frames keep `topic_signal = topic` — it IS the declaration, byte-identical to the Rust hook's cycle frames (parity preserved).
      - file absent → canary check (ADR-006), subagent-gated: if the event is in subagent context (depth ≥ 1 / SubagentStart) and the root session_id it carries (the expected-inherited id) has no `cycles/{session_key}.json` → `state.bumpStampMiss` (unambiguous inheritance drift). A depth-0 top-level session with no tracker is a never-declare session → no increment, no readdir. The carried root id is checked via the normal `cycles.readCycle`; there is no concurrent-file scan.
   5. Transport/enqueue as today. A request enqueued on send failure is enqueued **post-decoration**, so replayed frames carry the stamp that was true at event time (correct semantics: attribution reflects the declaration active when the event occurred).
3. **Suppression mechanism is strip-at-decoration**, not extraction-time branching: extraction code paths (`extractEventTopicSignal`, `topic-signal.js`) remain byte-unchanged and fully active for unstamped sessions (the vote floor for never-declare sessions, AC-07). One rule, one site, no purity violation.
4. **TranscriptDelta frames are NOT stamped**: delta events are F2-buffer-bound, not observation rows — `load_cycle_observations` (observation.rs:308) windows over `observations`/`cycle_events`, never transcript content. Stamping them spends bytes for no consumer. If a future consumer attributes buffer content, it inherits the marker-recovery follow-up (ADR-007 §4), not this seam.
5. **Cycle stop ordering**: lifecycle (step 3) runs before decoration (step 4), so the `cycle_stop` frame itself goes unstamped — by design. Its `payload.feature_cycle` + `topic_signal = topic` already declare it; the server's cycle-event arm assigns `topic_source = 'declared'` for all CYCLE_* rows regardless of stamp (ADR-005), so no information is lost.
6. **Sync-path budget audit**: sync trio — zero new I/O (decoration is inside the FNF branch). FNF happy path — exactly one JSON read (`readCycle`). FNF miss path — no readdir: the depth/subagent-context check plus a conditional `state.bumpStampMiss` (one health.json read-modify-write, only on detected inheritance drift), wrapped/never-throw. `pruneCycles` piggybacks where `queue.prune` already runs (FNF, best-effort).
7. **The stamp rides BOTH transports identically — transport-agnostic by construction (post-F4a obligation to #699).** Decoration mutates the in-memory `request` (HookRequest) object **before** transport selection: `selectTransport(config)` runs once at `index.js:410`, after the decoration seam, and the chosen transport is threaded through `runFireAndForget` (`transport.post`, `index.js:273`) **and** `queue.replay` (`index.js:269`). Both transports serialize the **same** decorated object via `JSON.stringify`: HTTP at `transport-http.js:74` (`JSON.stringify(frame)`), UDS at `transport-uds.js` `encodeFrame` → `:62` (`Buffer.from(JSON.stringify(payloadObj), "utf8")`). Therefore an event's `cycle_stamp` is byte-identical on the UDS frame and the HTTP body — the stamp is never transport-specific, because decoration is strictly upstream of the transport fork. Replayed (queued) frames inherit the stamp likewise, since the queue stores the post-decoration `request`.
   - **Binding design obligation — UDS-path stamp regression (was deferred until F4a; F4a has landed).** A regression test MUST prove the stamp survives the UDS transport, not only HTTP. **Seam location**: drive a stamped FNF `RecordEvent` (tracker file present) through `index.js` `runFireAndForget` with a UDS-mode config (`config.mode = "uds"`), and assert the bytes produced by `transport-uds.encodeFrame` (`transport-uds.js:55-62`) carry `cycle_stamp` in the decoded JSON payload, byte-equivalent to the HTTP path's `transport-http.post` body for the same input. This is the concrete discharge of vnc-027's post-merge obligation owed to #699 ("prove stamp decoration works over the new UDS transport"). The spec carries the matching AC; this ADR fixes the architectural assertion and the test seam.

### Consequences

Easier: vnc-030's only change to the vnc-027-contended files is in `index.js` orchestration, minimizing rebase conflict surface (SR-09); buildRequest's purity contract and its unit-test corpus survive untouched; suppression and stamping are observable at one seam (single decoration function = single test point; the post-rebase seam-survival test of ADR-007 §1 exercises it end-to-end). Harder: the decoration must iterate `RecordEvents` batches (queue replay shapes) as well as single frames — one loop, but it must not miss a frame class (mitigated by the AC-02 round-trip fixture set covering both); cycle_stop frames being unstamped is a rule downstream agents must not "fix" (documented here and in ADR-005's taxonomy).

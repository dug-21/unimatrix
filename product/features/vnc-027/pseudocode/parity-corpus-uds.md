# Component: parity-corpus-uds (UDS layer of the F3 parity corpus, NEW tests)

ADR-007 §3, ADR-001, ADR-002, ADR-003. FR-15, FR-20..FR-26, AC-01, AC-03, AC-04,
AC-07. Risks R-05, R-09, R-10, R-18, R-01. Merge step 3 (with transport-uds).
Extends the F3 corpus mechanism (vnc-026 ADR-001 oracle/golden/drift).

## Purpose

Add a UDS layer to the existing parity corpus: Rust-generated framing fixtures,
hash-fixture corpus, live-listener round-trip, sync-trio stdout goldens, and
cross-transport replay. The corpus covers the POST-REDUCTION TS event set only;
retired PreToolUse observation and default-off SubagentStop are excluded by design
(FR-21), and the lone-surrogate divergence is formally excepted (FR-22 — no
lone-surrogate inputs in byte-compare cases).

This is a test/fixtures component, not shipped client code (does not count against
the size budget).

## Sub-layers (the brief's five)

### (a) Framing fixtures vs wire.rs (AC-01, R-18)

Rust-generated goldens: `(payload_json, expected_frame_bytes)` where
`expected_frame_bytes = write_frame(payload)` from wire.rs. TS asserts
`transportUds.encodeFrame(parse(payload_json), {})` byte-equals the golden.

```
FOR each (payloadJson, frameBytesGolden) in framing_fixtures:
    assert encodeFrame(JSON.parse(payloadJson), {sync:false}) == frameBytesGolden
// boundary cases (R-18 s3): zero-length payload, exactly 1,048,576-byte payload,
// >1 MiB payload (encodeFrame returns null → assert null, no frame).
// read side: feed crafted headers (len 0, 1 MiB+1, 0xFFFFFFFF) into the read loop;
// assert connect-class reject BEFORE body allocation (R-18 s2, R-06 s3).
```

Generated by the existing corpus generator (so a future wire.rs change breaks the
drift check, not silently splits behavior).

### (b) Hash-fixture corpus (ADR-007 §3, FR-15, AC-02, R-05)

Rust-generated `(input layout, expected root, expected hash)` goldens for at least:
main repo root, deep subdir, linked worktree, symlinked repo path, non-git dir.
The generator creates real worktrees/symlinks at generation time and cleans up.

```
FOR each (startDir, expectedRoot, expectedHash) in hash_fixtures:
    root = config.walkToProjectRoot(startDir)
    hash = config.computeProjectHash(root)
    assert root == expectedRoot AND hash == expectedHash      // R-05 s1
// corrupt-worktree fixture (dangling gitdir:): assert the ONE documented divergence
//   exactly (Rust raw-cwd vs TS realpath-of-containing-dir) and nothing else — R-05 s2.
// single-derivation invariant: socketPath dirname and stateDir share {projectHash}
//   for every fixture — R-05 s3.
```

### (c) Live-listener round-trip (AC-03, FR-20b)

Full post-reduction event corpus sent over UDS to a live listener; assert the
listener received byte-identical HookRequest frames (extends F3 HookRequest goldens
for non-retired events).

```
spawn a real listener on a temp socketPath
FOR each event in POST_REDUCTION_EVENT_SET:
    frame = buildRequest(event, input)
    IF frame === null: continue                  // retired PreToolUse observation excluded (FR-21)
    res = transportUds.post({socketPath}, frame, opts)
    assert listener-recorded frame bytes == committed golden
```

### sync-trio stdout goldens (AC-03, FR-20c, R-09)

ContextSearch (plain + SubagentStart envelope), CompactPayload, Ping — stdout
byte-compared to Rust-hook stdout via `transform.writeSyncOutput(reqSource, res)`.

```
FOR each (reqSource, request, stdoutGolden) in sync_trio_goldens:
    res = transportUds.post({socketPath}, request, {sync:true})   // accept injected
    capture transform.writeSyncOutput(reqSource, res) stdout
    assert stdout == stdoutGolden
// R-09 s1: ContextSearch plain, ContextSearch-under-SubagentStart envelope,
//          CompactPayload, Ping/briefing.
// R-09 s2: Text{body} for Entries starts with "--- Unimatrix Context ---\n" exactly;
//          BriefingContent body verbatim (no header).
// R-09 s3: HTTP text/plain body == UDS Text body for the same request (shared core).
// Ping → Pong JSON → SendResult {200, application/json}; transform writes nothing
//        (not text/plain) — assert silent.
```

### cross-transport replay (AC-04, SR-10, R-10)

```
// direction 1: enqueue under UDS (no daemon) → next spawn resolves HTTP config →
//   queue.replay over transport-http.post → stubbed /observe accepts with fresh token.
// direction 2: enqueue under HTTP (server down) → next spawn resolves UDS →
//   queue.replay over transport-uds.post → live listener accepts.
assert both directions: replayed frames accepted at the ingest point.
assert session-id consequence pinned: HTTP ingest → http-{sid}; UDS → raw {sid} — R-10 s2.
assert replay-before-send order preserved; failed replay leaves frame queued (FR-26) — R-10 s3.
assert poison-pill (malformed queue file) does not abort subsequent replays — R-10 s4.
```

### FNF truncation assertions (ADR-003 §6, R-01)

```
// live-listener max-size (1 MiB) FNF frame: assert daemon recorded the event complete.
// kill-mid-write: assert either full delivery OR a clean server-side frame error
//   (read_exact rejects short frames) — never a silently truncated accepted event.
// instrument the socket: destroy() never called before 'finish' on the FNF path (R-01 s3).
// flush-timeout → ok:false → enqueued (at-least-once, duplicate accepted) (R-01 s4).
// server EPIPE on Ack write to FIN'd socket stays DEBUG (#3448) — no WARN noise (R-01 s5).
```

### delta-over-UDS (AC-07, FR-24)

```
// stream transcript_delta RecordEvents over UDS from the TS client through
//   listener.rs:785,1025 into the F2 session buffer; assert buffer CONTENT (not
//   just acceptance). PreCompact: with streamed deltas, exactly ONE server-built
//   block in CompactPayload output (AC-06, FR-23) — no client-side prepend.
```

## Accepted-divergence register (FR-22, ARCHITECTURE parity bar — corpus must except EXACTLY these)

1. Lone-surrogate stdin (#4788): no lone-surrogate inputs in byte-compare cases;
   remains a tracked `node:test` todo, NOT a UDS regression.
2. No bare probe connection: TS posts connection-per-frame, no empty first
   connection; wire frames and observable behavior identical.
3. PreCompact block source: TS never client-prepends; server builds from F2 buffer.
4. Event-set divergence by design: retired PreToolUse observation + default-off
   SubagentStop excluded from the corpus; absence is never a parity failure.

Any NEW divergence discovered during F4a is fixed or added to this register by
explicit decision — never silently tolerated.

## Drift mechanism (vnc-026 ADR-001)

All Rust-generated goldens (framing, hash, HookRequest, stdout) flow through the
existing corpus generator + drift check, so a future Rust-side change (wire.rs,
project.rs resolution, format_injection) breaks the drift check loudly instead of
silently splitting behavior.

## Error handling

Test harness: no listener → assert FNF enqueue + one stderr line + sync silent +
exit 0 (AC-04, R-13). Use async spawn-level tests for stdout-flush ordering (NEVER
`spawnSync` with an in-process stub — #4774, R-06 s6).

## Key test scenarios (consolidated, hints for tester)

Covered above per sub-layer: AC-01 framing + R-18 caps; AC-02/FR-15 hash fixtures +
R-05; AC-03 round-trip + sync goldens + R-09 envelope/header dispatch; AC-04
cross-transport replay both directions + R-10; AC-06/AC-07 delta + PreCompact single
block; ADR-003 §6 FNF truncation + R-01. The accepted-divergence register pins
exactly the four enumerated divergences.

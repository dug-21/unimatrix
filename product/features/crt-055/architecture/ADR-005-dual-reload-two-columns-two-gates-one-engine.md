## ADR-005: Dual Reload Metrics — Two Columns, Two Gates, One Overlap Engine, Never Collapsed

### Context
crt-055 surfaces TWO distinct reload signals (SCOPE In-scope item 3, Constraint 5, SR-06). They measure different things and must never collapse into one number: `context_reload` is CROSS-SESSION file overlap (continuity/handoff cost between a cycle's sessions), already live from #758 (`compute_context_reload_pct`, `unimatrix-observe/src/session_metrics.rs:47`). `compaction_reread` is POST-COMPACTION WITHIN-CYCLE re-read (the compaction tax — ass-077's most faithful reload, RQ-2 rank-5), with no durable gate until crt-054 supplies `compaction_events` rows with a durable `compacted_at` boundary. Both are file-overlap reckonings, so the temptation is to compute one overlap window and call it "reload" — which would conflate two semantics (SR-06).

### Decision
Two columns, two gates, one shared overlap primitive:
- **`context_reload_pct`** (INTEGER NOT NULL DEFAULT 0 — **basis points 0–10000**): promoted from #758's `compute_context_reload_pct`, which returns a *percentage*. crt-055 stores it as basis points: `round(pct × 100)` as `i64` (37.5% → 3750). Window = cross-session: PostToolUse file reads in a later session overlapping files read/written in an earlier session of the same cycle. crt-055 only promotes the existing signal to a durable column; it does not re-derive the overlap. **Stored as INTEGER, not REAL (human decision, 2026-06-16):** storing 0–10000 as an integer keeps EVERY metric column on `cycle_review_index` integer-typed (uniform with the crt-047 template), makes cross-cycle baseline queries cleaner, and avoids the float-bind footgun (`is_finite()` guard + `push_bind(f64)`, the #4529/#4533 trap) outright — there is no REAL column and no f64 ever bound. The percentage→basis-points conversion (`round(pct × 100)`) happens at the persist boundary; presentation divides by 100 to display a percentage.
- **`compaction_reread_count`** (INTEGER NOT NULL DEFAULT 0): window = within-cycle post-compaction. For each of the cycle's sessions, count PostToolUse file-overlap reads whose **`read_ts_secs > compacted_at`** (the gate boundary, ADR-006) re-reading a file already read before that boundary in the same session. The read `ts` is epoch millis and is normalized to seconds (`÷1000`) before the comparison — `compacted_at` is seconds (ADR-006, Binding constraint 8). Gated entirely on `compaction_events` rows (crt-054 Surface A).
- **`compaction_count`** (INTEGER NOT NULL DEFAULT 0): COUNT of `compaction_events` rows attributed to the cycle via the declaration chain. Distinct from the reread count.

Both reread metrics reuse ONE overlap primitive (the file-set-intersection logic), parameterized by the window; the engine is shared, the windows and gates are not. Each carries its own presence flag (ADR-003): zero `compaction_events` → `compaction_reread` "unavailable" (no boundary), never `0`.

### Consequences
Easier: the two signals stay semantically distinct and independently fail-loud; the shared overlap primitive avoids duplicate intersection logic; promoting #758 as-is avoids re-litigating the cross-session window; the basis-points integer keeps the whole column set integer-typed and dodges the float-bind footgun (#4529/#4533). Harder: the two windows must be pinned and tested separately so a refactor cannot silently merge them (SR-06); `compaction_reread` depends on a **unit-correct** gate — the read `ts` is epoch millis and `compacted_at` is seconds, so the gate MUST normalize the read `ts` to seconds first (ADR-006, Binding constraint 8) or it silently breaks (every read passes); the basis-points conversion adds a `round(pct × 100)` at persist and a `÷100` at presentation (a one-line each-way translation, tested for round-trip).

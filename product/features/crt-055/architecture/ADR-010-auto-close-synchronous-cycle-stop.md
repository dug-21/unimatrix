## ADR-010: auto_close (#593) Writes cycle_stop Synchronously Before the Pipeline, Idempotently

### Context
SCOPE In-scope item 6 folds #593: an `auto_close: bool` parameter (default `false`) on `context_cycle_review`. When `true` and the cycle has no `cycle_stop` event, the stop event is written atomically with the final retrospective so the cycle closes as part of the review. The rank-1 phase aggregates (ADR-004) read the `cycle_events` timeline including `cycle_stop` for closed-phase durations and #556 never-closed detection; if the stop is written AFTER reckoning, the final phase reads as never-closed. So ordering matters: the stop must exist before rank-1 reads the timeline. Constraint 2 forbids a second writer near the memo/check site — `auto_close` writes a `cycle_events` row (a separate table/path), not a `cycle_review_index` row, so it does not violate the single `store_cycle_review` writer.

### Decision
`auto_close: bool` (default `false`). When `true` AND no `cycle_stop` row exists for the cycle, the handler writes the `cycle_stop` event SYNCHRONOUSLY at the TOP of the full-pipeline block, before rank-1 phase reckoning reads the `cycle_events` timeline — so the final phase closes and is not mis-counted as never-closed (#556). The write is IDEMPOTENT: it checks for an existing `cycle_stop` first and is a no-op if one exists (re-review with `auto_close=true` does not write a duplicate stop). It uses the existing cycle_events write path (not a new writer; confirm the synchronous-callable helper at spec, Open Q2/§10). `auto_close=false` (default) leaves the timeline exactly as-is — an open cycle stays open and its final phase surfaces as never-closed per #556, which is correct fail-loud behavior, not an error. `auto_close` is a review-input convenience, never an orchestration control (informs/closes a record; does not control execution — RQ-8 edge).

### Consequences
Easier: the common "final retrospective also closes the cycle" flow is one call; the timeline is consistent before reckoning so #556 detection is accurate; idempotency makes re-review safe. Harder: the synchronous stop-write must be ordered before rank-1 reckoning and must reuse the existing event writer (not introduce a second writer); the default-false path must preserve never-closed surfacing rather than silently auto-closing. Cross-refs: #593 (auto_close), #556 (never-closed phases, ADR-004), ADR-004 (rank-1 timeline reckoning), ADR-002 (single cycle_review_index writer — auto_close writes cycle_events, a different path), Constraint 2, SCOPE Open Q2 / §10.

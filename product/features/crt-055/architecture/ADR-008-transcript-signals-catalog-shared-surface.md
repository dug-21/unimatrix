## ADR-008: [transcript_signals] Config Shape + Default Domain-Neutral Catalog (Shared Producer/Consumer Surface)

### Context
The `[transcript_signals]` catalog is the SHARED producer/consumer surface: crt-054 compiles it into the one `RegexSet` that produces `class_counts` (crt-054 ADR-002 / #5027); crt-055 surfaces the resulting counts by fixed index (`class_counts[0]=error`, `[1]=refusal`) into columns and `signal_class_counts_json`. SCOPE flags this as the question the human asked to decide HERE, jointly with crt-054's ADR-002. Constraints: the fold runs on the hot ingest path under the buffer lock (one shared `RegexSet` pass per delta, never one pass per pattern); the catalog must be domain-NEUTRAL (behavioral signatures, never SDLC literals); bounded (`MAX_SIGNAL_CLASSES`); `validate()`-rejects loud at startup; keep tiny + high-precision, under-catalog and let domains extend. dsn-001/#4591 set the externalized-config-with-cap precedent; `MAX = 16`.

### Decision
**`MAX_SIGNAL_CLASSES = 16`** (the small fixed bound; dsn-001/#4591 precedent). Config section `[transcript_signals]` (sibling to `[retention]`), `#[serde(default)]`, per-entry `{ class_name: String, pattern: String, enabled: bool }`, compiled once at load into one shared `regex::RegexSet`; `validate()` rejects >16 enabled classes, invalid regex (compile at load → fail startup loud), and duplicate `class_name`. Fixed v1 indices, contract-pinned: **`0 = error`, `1 = refusal`**. Match semantics: match-PRESENCE per delta (`set.matches(bytes)` once; each matched class `+= 1`, bounded by `delta_count`), a delta may match multiple classes. The default catalog is deliberately tiny and high-precision (under-catalog):
- **`error`** (index 0): provider hard/overload error signatures — e.g. patterns matching "rate limit", "overloaded", "internal server error", "service unavailable", "5xx" provider-error phrasings. NOT application/SDLC error literals.
- **`refusal`** (index 1): model refusal phrasings — e.g. "I can't help with that", "I'm unable to", "I cannot assist with" canonical refusal openings. Behavioral, domain-neutral.

Exact regex strings are tuned at spec/delivery for precision (high-precision over recall — a missed signal is better than a false positive that pollutes a cross-cycle baseline); domains extend via config without code change. No token-named class, no `reread`/`compaction` class (those are Surface A / review-time reckoning, not in-stream signatures — crt-054 ADR-002/#5027, ADR-005/#5030).

### Consequences
Easier: a stable shared catalog with fixed `0=error`/`1=refusal` indices lets crt-055 land columns by index and crt-054 produce by the same index; the cap bounds both the hot-path cost and the domain-assumption surface; invalid configs die loud at startup; `signal_class_counts_json` (ADR-007) carries any domain-added classes without a migration. Harder: must ship a sensible domain-neutral default that is high-precision across providers; the two features must agree on the exact default strings at delivery (a joint spec point); over-cataloging would dilute precision (deliberately avoided). Cross-refs: crt-054 ADR-002 (#5027, the producer side of this shared catalog), ADR-005 (#5030 no-token), dsn-001/#4591 (externalized capped config), ADR-007 (the columns/json this feeds), SCOPE Open Q4.

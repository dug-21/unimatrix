# infra-003 Acceptance Criteria Map

> Test-only feature. **Bidirectional 2×2** across two write surfaces — four
> mutually non-substring markers (`infra003-obs-a-<run>`, `infra003-obs-b-<run>`,
> `infra003-mcp-a-<run>`, `infra003-mcp-b-<run>`); each surface's verdict is the
> full matrix (each store holds only its own marker, present-in-own / absent-in-
> other, both directions). **This map is the authoritative AC tracker** — it carries
> the full **AC-01…AC-15** (AC-15 = MCP per-session isolation, grouped with the
> MCP-write surface). SCOPE's higher-level AC-01…AC-14 list is a known, non-blocking
> drift. Verification methods from specification/SPECIFICATION.md.
>
> Verdict discipline: GREEN / RED (exit 1) / INFRA (distinct) / SKIP (exit 3) — no
> non-pass rounds to exit 0. Route-liveness (non-404) is a precondition, never the
> verdict. **Durability = read-as-barrier**: the positive-control marker-keyed read
> is its own barrier (no aggregate `store_size` "store grew" gate); own-store
> timeout = INFRA (never RED), wrong-store presence = RED.
